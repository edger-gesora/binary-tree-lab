# Lab: Binary Trees - Depth and Ancestors

## Description
This project implements core binary tree and binary search tree (BST) algorithms in Python:
1. **Maximum Depth of Binary Tree**: Recursively calculates the maximum depth (height) from the root to the farthest leaf node[cite: 24, 26].
2. **Lowest Common Ancestor (LCA)**: Efficiently finds the lowest common ancestor of two nodes in a BST by leveraging tree ordering properties[cite: 24, 27].

## Features
- **Recursive Tree Traversal**: Clean recursive functions with proper base case handling for empty trees.
- **BST Optimization**: Iterative/structural search navigation taking advantage of BST sorting invariants[cite: 25, 27].
- **Robust Edge Case Handling**: Safely handles empty nodes, single-node trees, and multi-level diverging branches.
